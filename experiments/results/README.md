# Results

One file per study of the interruption classifier, in the order they were run.
Start with `interruption_summary.md`.

| File | Study |
|---|---|
| `interruption_summary.md` | One-page summary and shipped model |
| `interruption_eval_set_verification.md` | BEATs and DNSMOS checks of the augmented AMI eval sets |
| `interruption_baselines.md` | Energy, Silero VAD and transcript-rule baselines |
| `interruption_teacher_model.md` | WavLM-base+ teacher and leakage ablation |
| `interruption_student_model.md` | Whisper-tiny student, ONNX/INT8, latency, caller-only variant |
| `interruption_turnbench.md` | Out-of-domain test on TurnBench dev |
| `interruption_agent_calls.md` | Self-recorded TTS-agent calls, failed fixes, held-out test |
